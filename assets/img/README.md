# Images

**`logo.png`** — the AWeblo logo. Upload it here with exactly that filename and the whole
site picks it up: header, footer, browser tab icon, phone home-screen icon and the social
share preview.

Square works best (the logo is a square with a black background). Any size is fine — it's
displayed at 38px in the header.

Until the file is here, the logo spot renders as empty space; the "AWeblo" wordmark text
next to it still shows, so nothing looks broken.
